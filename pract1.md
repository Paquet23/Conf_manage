## Задача 1

```bash
grep -oE '^[^:]+' /etc/passwd | sort
```

Команда извлекает первое поле (имя пользователя) из `/etc/passwd` до первого двоеточия с помощью регулярного выражения и сортирует результат по алфавиту.

## Задача 2

```bash
grep -v '^#' /etc/protocols | awk '{print $2, $1}' | sort -k2 -nr | head -n 5
```

Фильтрует комментарии, меняет местами имя и номер протокола, сортирует по убыванию номеров и выводит 5 наибольших значений.

## Задача 3

Файл `banner.sh`:

```bash
#!/bin/bash
text="$1"
len=${#text}
border=$(printf '%*s' "$((len + 4))" '' | tr ' ' '*')

echo "$border"
echo "* $text *"
echo "$border"
```

Скрипт принимает текст первым аргументом, вычисляет его длину и рисует рамку из звёздочек, размер которой автоматически подстраивается под длину текста.

## Задача 4

```bash
grep -oE '[a-zA-Z_][a-zA-Z0-9_]*' "$1" | sort -u
```

Регулярное выражение находит все последовательности, соответствующие правилам идентификаторов C/C++/Java (начинаются с буквы или `_`, далее буквы, цифры или `_`). `sort -u` убирает повторения.

## Задача 5

Файл `reg.sh`:

```bash
#!/bin/bash
if [ -z "$1" ]; then
    echo "Использование: reg <имя_файла>"
    exit 1
fi

chmod +x "$1"
sudo cp "$1" /usr/local/bin/
echo "Скрипт $1 зарегистрирован в /usr/local/bin/"
```

Программа выставляет исполняемые права доступа на файл и копирует его в `/usr/local/bin`, после чего команду можно вызывать из любой директории по имени.

## Задача 6

Файл `check_comments.sh`:

```bash
#!/bin/bash
for file in "$@"; do
    ext="${file##*.}"
    first_line=$(head -n 1 "$file")
    has_comment="Нет"

    case "$ext" in
        c|js) [[ "$first_line" =~ ^[[:space:]]*(//|/\*) ]] && has_comment="Да" ;;
        py)   [[ "$first_line" =~ ^[[:space:]]*# ]]      && has_comment="Да" ;;
    esac

    echo "$file: $has_comment"
done
```

Для каждого переданного файла определяется расширение, затем первая строка проверяется на наличие комментария соответствующего языка (`//` или `/*` для C/JS, `#` для Python).

## Задача 7

Файл `find_duplicates.sh`:

```bash
#!/bin/bash
find "$1" -type f -exec md5sum {} + | sort | awk '{print $1}' | uniq -d | while read -r hash; do
    grep "^$hash " | cut -d' ' -f2-
done
```

Скрипт вычисляет MD5-хэши всех файлов в указанном каталоге, находит хэши, встречающиеся более одного раза, и выводит имена файлов-дубликатов.

## Задача 8

Файл `archive_by_ext.sh`:

```bash
#!/bin/bash
dir="$1"
ext="$2"
archive="archive.tar"

find "$dir" -type f -name "*.$ext" -print0 | tar -cvf "$archive" --null -T -
echo "Архив $archive создан."
```

Ищет все файлы с заданным расширением в указанном каталоге и упаковывает их в tar-архив. Использование `-print0` и `--null` обеспечивает корректную работу с именами, содержащими пробелы и спецсимволы.

## Задача 9

Файл `spaces_to_tabs.sh`:

```bash
#!/bin/bash
sed 's/    /\t/g' "$1" > "$2"
```

С помощью `sed` все последовательности из 4 пробелов заменяются на символ табуляции. Входной и выходной файлы передаются как аргументы.

## Задача 10

```bash
find "$1" -type f -empty -name "*.txt"
```

Команда ищет все пустые файлы с расширением `.txt` в указанном каталоге (включая подкаталоги).
